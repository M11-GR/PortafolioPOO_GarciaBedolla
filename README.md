## Descripción General
Este repositorio conforma el portafolio técnico de Programación Orientada a Objetos Reúne un conjunto de soluciones de software estructuradas, diseñadas e implementadas a lo largo del periodo escolar, con el fin de consolidar los principios fundamentales de la ingeniería de software y el paradigma orientado a objetos.

A través de estos desarrollos, se aborda de manera práctica el modelado de sistemas utilizando abstracción de datos, la encapsulación de lógica mediante el diseño de clases y objetos, la modularidad y comportamiento a través de métodos, así como la reutilización de código mediante relaciones de herencia estructural.

### Tecnologías Utilizadas
* **Lenguajes de Programación:** PHP, Python
* **Desarrollo Front-end:** HTML, CSS
* **Entorno de Desarrollo y Servidor:** XAMPP (Apache)
* **Control de Versiones:** GitHub

### Competencias Desarrolladas
* **Modelado Orientado a Objetos:** Capacidad para traducir problemas del mundo real en arquitecturas de software basadas en clases, atributos y métodos específicos.
* **Extensibilidad y Reutilización:** Implementación de herencia para construir jerarquías de clases sólidas, reduciendo la redundancia de código y mejorando el mantenimiento del software.
* **Lógica de Programación Avanzada:** Manejo de estructuras de datos lineales (arreglos) y persistencia/gestión de información a través de manipulación de archivos de texto.
* **Gestión de Entornos Locales:** Configuración, administración y despliegue de scripts y entornos web mediante el servidor local Apache en XAMPP.

## Lista de Proyectos Incluidos

De acuerdo con la organización jerárquica de archivos establecida para este portafolio, se incluyen y documentan los siguientes cinco proyectos y actividades evaluativas:

1. **Proyecto 01: Examen contra reloj (Corte 1 Unidad 2)**
   * *Enfoque:* Evaluación práctica centrada en la resolución ágil de algoritmos y modelado inicial de objetos bajo restricciones de tiempo.
2. **Proyecto 02: Actividad de evaluación C2 - Consumo energético servidores Unidad 3 – Métodos**
   * *Enfoque:* Aplicación orientada al cálculo, análisis y optimización del consumo de energía en infraestructura tecnológica utilizando métodos de clase avanzados y paso de parámetros.
3. **Proyecto 03: Actividad de evaluación c3 – usuarios**
   * *Enfoque:* Módulo de gestión, control y validación de entidades de usuario empleando encapsulamiento para proteger la integridad de los datos.
4. **Proyecto 04: Actividad Integradora - Arreglos unidimensionales**
   * *Enfoque:* Implementación de colecciones de objetos y estructuras de almacenamiento lineal manejadas a través de lógica orientada a objetos.
5. **Proyecto 05: Actividad Integradora - Gestión de Bitácoras en Archivos de Texto**
   * *Enfoque:* Sistema avanzado de registro y persistencia de eventos (logs) mediante lectura y escritura de archivos planos utilizando clases dedicadas y manejo de flujos de datos.
